# J280 旋转倒立摆双环 PD 控制

本工程为独立的源码工程，采用位置外环 PD 生成目标倾角、角度内环 PD 生成电机驱动量。控制器不含积分累加器，也不含基于位置偏差累积的目标修正器。串口仅用于监测，运行参数在硬件源代码中固定。

## 硬件

硬件平台采用官方 J280 姿态控制开发套件。

- 芯片：GW2A-LV55PG484C8/I7，系统时钟 50 MHz。
- 转换器：3PA1030，并行十位采样，换算为 0～1650 控制码，存储宽度十二位。
- 电机：XH2 接口，按原理图对应甲通道驱动与第二组编码器；第一组驱动保持关闭。
- 串口：115200，八数据位、无校验、一停止位，仅发送遥测。
- 引脚与电平在约束文件中定义。溢出指示保持忽略，采样超时与机械保护独立执行。

## 操作

第一按键启动自动起摆或停止。故障后第一次按键回到停止态，第二次按键才允许重新启动。上电不自动驱动电机。

第二至第五按键分别将目标追加 60°、120°、180°、360°。拨码一选择方向。拨码二开启围绕当前目标的对称往复，单边幅度固定 45°、间隔 1.75 秒，关闭后保持最后目标。

只有平衡状态接收步进目标。启动位置用于起摆行程保护，捕获直立的位置用于平衡坐标原点。按键目标与往复端点均基于同一位置坐标。

## 文件结构

| 文件 | 职责 |
|---|---|
| `src/j280_board_top.v` | 板级端口、上电复位、按键与硬件连接 |
| `src/fixed_parameters.vh` | 增益、机械校准、起摆与目标参数 |
| `src/pendulum_core.v` | 状态机、保护、双环调度、遥测快照 |
| `src/angle_filter.v` | 环形位移换算及定点一阶低通 |
| `src/angle_pd.v` | 角度内环 PD |
| `src/position_pd_native.v` | 位置外环 PD 与倾角限幅 |
| `src/swing_three_pulse.v` | 最多三次交替冲击及捕获资格 |
| `src/board_target_control.v` | 步进累加与对称往复 |
| `tools/monitor.py` | 黑色四图只读界面与单图全屏 |
| `tools/monitor_protocol.py` | 数据解帧及物理单位换算 |

## 使用

高云开发环境打开 `j280_pd_pd.gprj`，选择 `j280_board_top` 为顶层；批量构建可运行 `build.tcl`。头文件搜索路径为 `src`。工具生成的实现目录不属于提交内容。

安装 Python 依赖后执行 `python tools/monitor.py`，手动选择串口连接。执行 `python tools/monitor.py --demo` 仅展示模拟曲线。黑色界面不依赖校准文件、不保存实验数据、不发送任何串口命令，连接与断开均不改变板端控制状态。

## 设计边界

本工程提供可审阅的控制结构与固定参数，不包含硬件下载产物。当前增益为固定设计参数，实际闭环性能需结合机械装置验证。PD 系统在恒定扰动和静摩擦下允许存在稳态位置偏差，不能以隐藏积分或修改遥测角度代替实际回正。

控制方程、参数来源、单位和保护见 `docs/control.md`；遥测定义见 `docs/protocol.md`。
